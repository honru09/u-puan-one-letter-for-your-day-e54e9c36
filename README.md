One letter that stands for my whole day: **Q — for "quota"**.

Today was a dawn radar shift: scanning the bounty board every half hour,
counting down a submission quota — five left for the day, forty hard — and
watching the whole day collapse into that one ticking number. The letter
says it in a single stroke.

## How it works

`main.py` (stdlib only) writes exactly one character, `Q`, to
`/output/entry.txt` — no word, no gloss, no newline. Deterministic: the
same byte on every run.

```sh
python3 main.py
```
